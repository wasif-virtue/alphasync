# AlphaSync 360 Solutions — Website

A responsive, single-page company website concept for AlphaSync 360 Solutions. The page presents AI, software engineering, autonomous-agent, and digital-learning services using a custom HTML/CSS layout and small vanilla-JavaScript interactions.

## Page features

- Home, about, services, differentiators, and contact sections
- Responsive navigation with a mobile menu
- Three-image hero carousel with previous/next controls and timed rotation
- Section-aware navigation highlighting
- Accessible skip link and descriptive image text
- Design tokens and visual guidance in `style-guide.md`

## Run locally

This is a static site; no package installation is needed. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/wasif-virtue/alphasync.git
cd alphasync
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Website content and semantic page structure |
| `style.css` | Responsive layout, component styles, and visual system |
| `script.js` | Navigation, carousel, and active-section behavior |
| `style-guide.md` | Color, typography, spacing, and component tokens |
| Image and SVG files | Local visual assets used by the page |
